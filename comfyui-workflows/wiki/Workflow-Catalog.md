## 一、 双轨架构原理 (Dual-Track Invariant)

每个生成类工作流在画布拓扑上均具备两条正交链路：

```mermaid
flowchart TD
    PromptNode["正向 / 负向提示词 (CLIPTextEncode)"]
    LatentNode["原生潜空间尺寸 (例如 512x768)"]

    subgraph QUALITY_TRACK ["【高精成片主干】(默认交付链路，保证绝对画质)"]
        KS_Q1["KSampler 基础构图<br/>26~28步 DPM++ 2M Karras, CFG 7.0"]
        Upscale["LatentUpscaleBy<br/>1.35x ~ 1.5x 双三次放大"]
        KS_Q2["KSampler 高分辨率精雕 (Refine)<br/>14~15步微雕重绘 (Denoise 0.35~0.46)"]
        VAEDecode_Q["VAEDecode (CPU-VAE 浮点保护)"]
        Save_Q["SaveImage [OUTPUT:QUALITY]"]

        LatentNode --> KS_Q1
        PromptNode --> KS_Q1
        KS_Q1 --> Upscale --> KS_Q2
        PromptNode --> KS_Q2
        KS_Q2 --> VAEDecode_Q --> Save_Q
    end

    subgraph PREVIEW_TRACK ["【快速预览旁路】(轻量探索链路，供 Agent 粗览)"]
        KS_P["KSampler 极速探索<br/>8步 Hyper-SD, CFG 2.0"]
        VAEDecode_P["VAEDecode (CPU-VAE)"]
        Save_P["SaveImage [OUTPUT:PREVIEW]"]

        LatentNode -.-> KS_P
        PromptNode -.-> KS_P
        KS_P -.-> VAEDecode_P -.-> Save_P
    end
```
