# Windows 桌面端无黑框体验指南 (Windows Guide)

本文档面向 **Windows 10 / Windows 11 (64位)** 桌面端用户，详细介绍原生无黑框托盘守护、全栈引导器以及开机自启等功能。

---

## 🖥️ 核心体验设计准则

1. **零黑框终端打扰**：配置或启动本地智能网关与托盘服务时，严禁在桌面上留下任何可见的 cmd/powershell/node.exe 黑框控制台；
2. **纯粹独立桌面应用交互**：管理控制台以 Edge / Chrome `--app=` 模式唤出，无地址栏、无标签页，呈现原生桌面软件质感；
3. **冷启动自愈与全栈引导**：双击快捷方式时毫秒级探测后台服务是否就绪；未就绪则 0.5 秒内静默拉起后台服务并瞬间呼出前端应用界面，彻底告别冷启动白屏。

---

## 🎛️ 桌面功能与快捷操作

### 1. 高光翡翠绿托盘菜单 (OpenCodeRouterTray.exe)
托盘小图标常驻在右下角任务栏通知区域：
- **鼠标左键单击 / 双击**：瞬间呼出或置顶 Web 管理控制台独立应用窗口；
- **鼠标右键快捷菜单**：
  - `打开管理后台`：唤出仪表盘控制台；
  - `唤醒 / 启动 OpenChamber 桌面端`：优先置顶本地 Electron 客户端，自动处理僵死单实例互斥锁；
  - `独立 Web 工作台 (3000 端口)`：在浏览器中打开 OpenChamber Web；
  - `重启网关服务`：平滑重载 4010 智能网关；
  - `重置冷却状态`：一键清除账号 429 冷却与重置限额；
  - `健康体检 (Doctor)`：调起一键体检诊断与自动修复；
  - `检查更新`：检测 5 大组件最新版本与兼容性；
  - `退出全套服务`：安全终止托盘与后台网关进程。


### 3. Windows PowerShell 转义优化与环境自适应防护 (Card 5)
Windows 下使用各种编程智能体（Codex / OpenCode / OpenChamber）时，PowerShell 往往是语法报错与命令失效的重灾区。网关内置了自适应 PowerShell 优化层：
- **末尾反斜杠防吃引号**：防止 `"C:\dir\"` 导致 Windows 传参吃掉闭合双引号引发解析混乱；
- **curl/wget 别名修正**：自动将原生命令重定向为 `curl.exe`，避免因 PowerShell 默认别名为 `Invoke-WebRequest` 发生崩溃；
- **&& 操作符兼容自愈**：将 Windows PowerShell 5.1 不支持的 `&&` 转换为 `; if ($?) { ... }`；
- **CLIXML 报错深度去噪**：剔除 `#< CLIXML` 冗长标签与 hex 转义，大幅减少重试 Token 开销。

## 🚀 开机自启机制

运行 `setup-wizard.ps1` 或在管理控制台勾选开机自启时，系统将在 Windows 启动目录（`shell:startup`）创建脱钩引导项：
- 调用 `launch-gui.vbs` 配套 `-Silent` 模式；
- 开机时后台静默启动网关与托盘，不弹出任何窗口打扰用户，开机即用。
